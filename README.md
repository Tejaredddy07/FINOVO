# FINOVO — Prototype Submission

**Tagline:** Smart Money. Smarter Future.

## Run the prototype
1. Extract `FINOVO_Submission.zip`.
2. Open `index.html` in Chrome or another modern browser.
3. Internet is needed for Google Fonts and Chart.js CDN.

No installation or build command is required.

## Included files
- `index.html` — page structure and navigation
- `css/styles.css` — responsive design, colors, typography and layout
- `js/app.js` — navigation, demo AI replies, expense modal and chart
- `SUBMISSION_NOTES.md` — project summary and limitations

## Important
This is a front-end prototype using sample data and rule-based demo AI responses. It does not connect to a database, authenticate real users, call a live AI model, or generate a real PDF. Do not enter real financial information.
